# Opportunity Archive

**Tarih:** 2026-09-02
**Durum:** Beklemede (Pivot öncesi B2B/Dev-Tool havuzu)

Bu listedeki fikirler "7 günde MVP" hedefine uygun olsalar da, araştırma kapsamımızı "Content, Service, Digital Products" alanlarına genişletme kararı (Pivot) sebebiyle arşive alınmıştır. Daha sonra değerlendirilmek üzere saklanmaktadır.

---

### 1. (Eski #4) Custom Code Reviewer for SOC 2 / Security Compliance
* **Niche:** SOC 2 uyumluluğu için PR'ların manuel incelenmesi.
* **MVP Zayıflığı:** Hedef kitle kurumsal, satış döngüsü 7 günden uzun sürebilir.

### 2. (Eski #5) Automated API Caching Proxy for LLM Calls
* **Niche:** LLM API maliyetlerini semantik önbellekleme ile düşürme.
* **MVP Zayıflığı:** Developerlara güven vermek (API keylerini proxy'den geçirmeleri) zor olabilir.

### 3. (Eski #9) AI Database Seeder (Context-Aware Dummy Data)
* **Niche:** Prisma/SQL şemalarından saniyeler içinde binlerce satır mantıklı/ilişkisel test verisi üretme.
* **Neden Saklandı:** Satışı çok kolay, PLG (Product Led Growth) potansiyeli yüksek, X/HN üzerinden organik trafik çekebilir. Yapımı 1 gün sürer.

### 4. (Eski #10) CI/CD YAML Pipeline AI Debugger
* **Niche:** Kırılan GitHub Actions loglarını okuyup çözüm öneren veya otomatik PR açan bot.
* **Neden Saklandı:** Anında acı çözer (iş durmasını engeller), değeri açıktır.
