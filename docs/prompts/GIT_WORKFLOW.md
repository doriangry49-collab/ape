# Git Workflow

Every implementation must follow this order.

1. Implementation
2. Ruff
3. Pytest
4. git status
5. Documentation
6. git add
7. git commit (only after user approval)
8. git push (only after user approval)
9. git status
10. SESSION_END_CHECKLIST

Rules:

- Never skip a step.
- GitHub is the single source of truth.
- Never finish a sprint with uncommitted work.
- Never finish a sprint without verifying the latest push.

Do not commit.
Do not push.
