# Sprint Start Checklist

Before writing any code:

- Read START_HERE.md
- Read docs/memory/PROJECT_CONTEXT.md
- Read docs/memory/NEXT_SESSION.md
- Read docs/prompts/AGENT_RULES.md
- Read docs/prompts/IMPLEMENTATION_CHECKLIST.md
- Read the relevant specification in docs/specs/ (if any)

Then verify:

- git status
- current branch
- latest 5 commits

Confirm:

- current sprint
- sprint goal
- expected deliverables

Only then begin implementation.

Do not commit.
Do not push.
